# 🚀 SalesFlow AI CRM – Intelligent Sales Pipeline Management

SalesFlow AI CRM is a full-stack MERN CRM application designed to help manage leads, sales activities, and customer information in one place.

## ✨ Features

- 📈 Sales dashboard with key metrics
- 📋 Create, view, update, and delete leads
- 🗓️ Track calls, emails, meetings, and notes
- 🔐 User registration and login with JWT authentication
- 🔒 Password hashing using bcrypt.js
- 💡 AI-powered sales features
- 🎨 Responsive UI with React and Tailwind CSS
- 🔄 Efficient data fetching with React Query
